# P0 design reference

Mode: built-in image generation. The generated images are implementation references, not runtime screenshots and not product evidence.

## Design read

Cinematic industrial diagnostic product for operators. Cold chrome and copper machinery sit on graphite surfaces. One red signal color marks the primary action. Controls are rectangular, copy is brief, and survey evidence stays separate from scenario output.

- Design variance: 8
- Motion intensity: 4
- Visual density: 5
- Shape rule: 4px controls and square mechanical panels
- Theme: dark only, following the supplied artwork
