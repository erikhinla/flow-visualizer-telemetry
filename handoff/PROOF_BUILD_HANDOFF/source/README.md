# FLOW Blueprint Visualizer

The application follows one work item across a handoff, exposes the human repair, identifies one connection to change, and preserves what must be measured next.

## Evidence boundary

- Momentum Map answers are `SURVEY-DERIVED`.
- Revision 3 manifestation output is an `ILLUSTRATIVE SCENARIO`.
- Department examples are investigation prompts, not findings about an organization.
- No questionnaire answers are transmitted or persisted by this P0 application.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Verification

```bash
npm run check
```

`check` runs TypeScript, unit tests, and the production build. Deployment is deliberately outside this P0 scope.
